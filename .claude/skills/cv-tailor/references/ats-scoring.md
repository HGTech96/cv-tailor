# ATS Keyword Scoring (used in Stage 4)

Purpose: estimate how well the draft covers the JD's keyword set, transparently.

## Method

1. Take the ATS keyword list from `01-analysis.md`.
2. For each keyword, check the draft for the keyword or an exact-equivalent form
   (plural/singular, verb form). Do NOT count loose synonyms as matches.
3. Produce a table:

| Keyword | In draft? | Where / why not |
|---|---|---|

4. Coverage % = matched / total.

## Interpretation

- **≥ 80%**: good; do not force in remaining keywords if they'd be untruthful or bloat the page.
- **60–80%**: review each miss — is there honest evidence in the master CV that got cut? If yes, consider swapping a weaker bullet.
- **< 60%**: likely a genuine fit gap; report it plainly rather than stuffing keywords. The matching stage (02) should already show why.

## Rules

- Never add a keyword the master CV cannot support.
- Never hide keywords (white text, tiny fonts, keyword blocks). The CV must read naturally to a human first.
- A keyword in the Skills line counts, but a keyword demonstrated in a bullet counts more — prefer the latter for must-haves.
