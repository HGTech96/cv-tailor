# CV Structure (fixed skeleton — every generated CV follows this order)

1. **Header**: Name (H1), one line: role title matching the target | city | email | phone | LinkedIn/GitHub
2. **Summary** (optional, max 2 lines — only for senior roles, see writing-rules.md)
3. **Experience**: reverse chronological. Per role: `### Title — Company` + dates line + bullets
4. **Skills**: max 3 category lines (e.g., Languages / Infrastructure / Practices)
5. **Projects** (optional — only when they beat a weak role for relevance)
6. **Education**: single lines, no bullets, no GPA unless recent grad
7. **Certifications** (optional, single lines)

Omit any empty section entirely. No other sections without user approval.
